## Course Structure

Each course includes comprehensive content for every module:

### Learning Components
- **Learning Objectives** - Clear goals for each module
- **Historical Context** - Detailed background and context
- **Key Readings** - Primary and secondary sources with significance notes
- **Discussion Questions** - Thought-provoking questions for reflection
- **Multiple Perspectives** - How different restoration traditions view the topic
- **Reflection Exercises** - Hands-on activities for deeper engagement
- **Additional Resources** - Maps, timelines, multimedia, and supplementary materials

### Pedagogical Approach

All courses follow these principles:

1. **Honest Inquiry Over Apologetics** - We're interested in what actually happened, not defending institutional positions
2. **Primary Sources First** - Prioritize documents, letters, and firsthand accounts
3. **Multiple Perspectives** - Present how different restoration traditions understand the same history
4. **Complexity Over Simplification** - Real history is messy; we embrace that
5. **Community of Christ Lens** - Non-apologetic, scholarly, progressive approach
6. **Accessible Scholarship** - Rigorous but readable for general audiences

## How to Use These Courses

### For Individual Learners
1. Read the historical context for each module
2. Engage with the key readings (many available online or in libraries)
3. Reflect on discussion questions
4. Complete one or more reflection exercises
5. Explore additional resources

### For Study Groups
1. Meet weekly or bi-weekly to discuss one module at a time
2. Assign readings in advance
3. Use discussion questions to guide conversation
4. Share insights from reflection exercises
5. Invite diverse perspectives

### For Instructors
1. Use modules as weekly lesson plans
2. Supplement with your own materials
3. Adapt reflection exercises to your context
4. Encourage students to engage multiple perspectives
5. Assess learning through discussion participation and written reflections
