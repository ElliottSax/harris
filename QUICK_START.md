## 🚀 Get Started in 3 Steps

### Step 1: View the Demo
```bash
Open this file in your browser:
/home/user/harris/courses-demo.html
```

### Step 2: Add to Your Site
Add these two lines to your `index.html`:

```html
<!-- In <head> after styles.css -->
<link rel="stylesheet" href="courses-enhanced.css">

<!-- Before </body> after script.js -->
<script src="courses-enhanced.js"></script>
```

### Step 3: Enjoy!
All features will work automatically with your existing courses section.

## 🔧 Quick Customization

### Change Colors
Edit in `courses-enhanced.css`:
```css
:root {
    --beginner-color: #4CAF50;
    --intermediate-color: #FF9800;
    --advanced-color: #F44336;
}
```

### Add Courses
Edit in `courses-enhanced.js`:
```javascript
const coursesData = [
    {
        title: "Your Course",
        difficulty: "beginner",
        modules: 6,
        // ... more properties
    }
];
```

### Change Achievements
Edit in `courses-enhanced.js`:
```javascript
const achievements = [
    {
        name: "Achievement Name",
        icon: "🎯",
        unlocked: false
    }
];
```
